# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| 1.0.x | :white_check_mark: |
| < 1.0 | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability in VOT UZ:

1. **Do not create a public issue.**
2. Report the issue confidentially via GitHub Security Advisories on the repository page under `Security -> Report a vulnerability`.
3. Alternatively, send an email describing the vulnerability to `360958645+abdurazzoqo@users.noreply.github.com`.

Please provide:
- A description of the vulnerability.
- Steps to reproduce or proof-of-concept.
- Potential impact.

We will acknowledge receipt within 48 hours and work on a prompt resolution.
